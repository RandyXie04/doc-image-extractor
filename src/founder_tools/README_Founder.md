# 方正書版亂碼修復模組

本目錄 (`src/founder_tools`) 包含了用於修復早期「方正書版 (Founder Bookmaker)」排版系統編碼異常的核心邏輯。

## 🛠️ 核心功能

*   **字型與編碼修復**：針對方正書版產生的 CMap 編碼缺陷，自動修復無法被正常選取或複製的亂碼、特殊字串與中英文標點符號。
*   **格式支援**：支援上傳 PDF 或 DOCX 進行字體編碼修復與結構重組。
*   **標題與排版重建**：包含 `HeadingDetector` 與 `toc_parser.py` 等元件，利用幾何、字體與語意特徵，重新建構破損文檔的章節階層。
