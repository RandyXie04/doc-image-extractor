書籍轉檔與文檔數位化工具箱

把書稿 PDF 轉成可排版的 Word 與 Markdown，再依人工預修範本擴散到全書。

主流程：書稿整稿

  1. 第 1 步

    全自動整稿

    先以視覺裁切去除頁眉頁尾，再自動重建標題階層、表格與圖片，產出初稿。

    輸出：Word、Markdown、圖片資料夾 images/書名/
  2. 第 2 步

    POD 整稿

    人工預修前 5%~10% 章節後，上傳預修 Word 與原 PDF，系統學習樣式並擴散到全書。

    輸出：成品 Word、Markdown、驗收報告 audit_report.json

輔助工具

  • 方正修復 PDF 或 DOCX 出現方正系統亂碼時，先修復編碼再進入整稿。輸出：修復後的 Word。
  • 圖片提取 從 PDF 或 DOCX 取出內嵌的原始畫質圖片。輸出：圖片 ZIP。
  • 公式提取 以 AI 模型定位獨立公式並裁切成圖片。輸出：公式圖片 ZIP。
