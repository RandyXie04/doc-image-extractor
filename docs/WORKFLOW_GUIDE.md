# 書籍數位化工具箱：全流程操作手冊

本文件說明書籍轉檔與文檔數位化工具箱的標準作業流程、主流程使用指引與各輔助工具搭配時機。

---

## 主流程一：全自動整稿 (OCR Pipeline)

適用於原稿 PDF 的初稿轉換，自動完成視覺裁切、標題階層分析、表格識別與圖文重排。

### 操作步驟

1. **上傳檔案**
   - 支援將書籍 PDF 拖曳至上傳區，或點擊瀏覽選取檔案（支援本機檔案路徑快速載入）。
   - 系統支援最大 200MB 單檔上傳，檔案超過限制時會提示分卷建議。

2. **四向邊界視覺裁切**
   - 預設載入頁面預覽，提供頂部（紅線）、底部（藍線）與左右側（綠線）裁切滑桿。
   - **去除頁眉頁尾**：拉動滑桿精確切除版心外的頁眉、頁碼與書名標註，避免頁眉污染內文段落。

3. **引擎與參數配置**
   - **辨識引擎**：
     - **向量解析 (PyMuPDF)**：適用原生數位 PDF，幾何文字流毫秒級抽取，100% 保留原生字元。
     - **深度 OCR (Surya OCR)**：適用圖書掃描件、雙層 PDF 或已轉曲字型，執行版面區塊切割與文字辨識。
   - **無腳注模式**：預設開啟，防止正文中的帶圈數字、序號或公式編號被誤判為腳注抽離。
   - **首字下沉修復**：自動識別章節開頭大型下沉裝飾字並合併回正文段落。

4. **執行轉檔與下載**
   - 點擊「開始全自動整稿」，系統啟動後台任務並顯示即時進度。
   - 轉檔完成後產出：
     - **結構化 Word (.docx)**：已套用階層樣式與表格格線之排版檔案。
     - **語意 Markdown (.md)**：乾淨標準 Markdown 內文。
     - **圖片資料夾 (`images/書名/`)**：頁面插圖無損切片。

## 主流程二：POD 整稿 (POD Studio)

適用於高品質出版排版需求。編輯人工精修前 5%~10% 章節後，系統自動學習排版樣式並擴散套用至全書剩餘內容。

### 操作步驟

1. **準備前導範本**
   - 取全自動整稿產出之初稿 Word，由人工排版編輯精修前 1~2 個章節（字體、行距、標題階層、表格樣式）。

2. **階段一：雙檔比對與樣式編譯**
   - 上傳「人工預修 Word 範本 (`.docx`)」與「原版書籍 PDF (`.pdf`)」。
   - 系統自動解析段落差異，抽取字體度量、段落間距、自訂樣式名稱與三線表座標資訊，建立 `Book_raw_ast.json`。

3. **階段二：樣式擴散與原位造表**
   - 系統依據預修範本所建立的樣式規則，自動擴散至全書未精修章節。
   - 原 PDF 綁定機制將後半部壓平的純文字數據段，自動原位替換為標準 Word `Table Grid` (`w:tbl`) 三線表格。
   - 產出最終成品 Word、校對 Markdown 與驗收報告 `audit_report.json`。

## 輔助工具搭配流程

輔助工具可作為獨立模組隨時單獨調用，亦可與主流程銜接：

| 輔助工具 | 最佳使用時機 | 輸入與輸出 |
| :--- | :--- | :--- |
| **方正修復** | 早期方正排版系統轉出之 PDF/DOCX 出現非標準字型或 CID 亂碼時，先修復再進入整稿。 | 輸入：亂碼 PDF/DOCX<br>輸出：字元修復後之 Word |
| **圖片提取** | 需批次無損導出書中插圖、照片或圖表，保留原始色彩空間與解析度。 | 輸入：PDF/DOCX<br>輸出：圖片打包 ZIP |
| **公式提取** | 理工、醫學教材中含有大量獨立數學、化學公式，需單獨截圖歸檔或後續處理。 | 輸入：書籍 PDF<br>輸出：公式截圖 ZIP |

## 資料安全性與作業規範

- **零日誌隱私架構**：系統執行過程不記錄敏感業務文本，所有中繼快取與產出檔案於 24 小時後自動清理銷毀。
- **作業模式切換**：
  - **出版社編輯模式**：隱藏技術底層細節，介面簡潔直覺。
  - **工程師除錯模式**：顯示 GPU 推論負載、字型映射詳細表與底層除錯日誌。
