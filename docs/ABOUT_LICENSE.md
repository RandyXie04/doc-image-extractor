## 二、第三方模型與工具授權規範 (法務與合規須知)

系統整合了多個開源演算法模型與相依組件，其授權各具獨立約束，請出版社與企業用戶特別留意：

### 1. Surya OCR 深度辨識模型 (CC-BY-NC-SA 4.0 - 非商業用途)
- **涵蓋範圍**：`models/surya_pt/` 之下之文字偵測 (`det`)、版面分析 (`layout`)、閱讀順序 (`order`) 與文字識別 (`rec`) 模型權重。
- **原始授權**：由 Vik Paruchuri 開源發布，採用 **Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC-BY-NC-SA 4.0)**。
- **非商業限制**：此系列模型權重**僅限非商業用途、學術研究及個人學習**使用，禁止直接用於商業營利行為。
- **商業合規建議**：
  - 出版社若進行營利性出版製作，建議優先切換至系統預設的「**高速向量通道 (PyMuPDF)**」；只要來源 PDF 為數位向量格式，即完全不經由 Surya OCR 運算，100% 依循原生字元度量萃取。
  - 如需掃描書商業 OCR，可替換為企業內部自訓模型或具備商業許可之 OCR 引擎。

### 2. Pandoc 文檔轉換核心 (GPL v2 / v3)
- **涵蓋範圍**：內建隨附之 `bin/pandoc.exe` 二進位執行檔。
- **合規設計**：系統透過獨立作業系統進程 (`subprocess.run`) 以 CLI 標準管道調用 Pandoc，未進行靜態或動態程式碼連結，符合自由軟體基金會 (FSF) 之進程隔離標準。

### 3. YOLOv8 (ONNX Runtime / DirectML)
- **涵蓋範圍**：`models/yolo_v8_ft.onnx` 數學公式定位模型。
- **執行框架**：透過微軟開源之 ONNX Runtime (MIT License) 與 DirectML 於本機 GPU/CPU 進行純本機離線推論。

## 三、純本地／區域網路 (LAN) 私有化部署架構

本系統已全面設計為**純本地與限定網域（Intranet / LAN）Web 應用**，不具備對外聯網更新依賴，確保出版文稿與版權資料 100% 留存於企業內部：

```text
[內網 GPU 運算主機] (執行 start_app.bat)
       │
       ├── http://192.168.1.100:8000
       │
       ├── 編輯同仁 A (瀏覽器操作，免配置 Python/模型)
       ├── 編輯同仁 B (瀏覽器操作，免配置 Python/模型)
       └── 審校主管 (即時預覽、邊界裁切與樣式擴散)
```

### 關鍵安全機制
1. **零外部連線**：轉檔、OCR 與公式提取全於伺服器主機內部運算，無任何數據回傳公有雲。
2. **零磁碟日誌 (Zero Disk Logging)**：系統運行過程不向磁碟寫入任何書籍內文日誌。
3. **檔案生命週期自動銷毀**：使用者上傳之原始檔與轉檔中繼產物，預設於 24 小時後由背景排程自動安全清除。
4. **角色視角切換**：
   - **出版社編輯模式**：隱藏工程參數，以直覺的工作流程為主。
   - **工程師除錯模式**：提供 GPU 資源監控、字體映射分析、AST 結構檢視與 GitHub 問題回報通道。
