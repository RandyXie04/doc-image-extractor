# Bug Log

## Bug Description
Pandoc conversion from MD to DOCX produces warnings: `[WARNING] Could not fetch resource : replacing image with description`.
This occurs because the image Markdown placeholders `![__IMG_PLACEHOLDER...__]()` are not separated by newlines, making Pandoc treat them as inline images that fail to resolve when the URL part `()` is empty. The regex added to `md_to_docx.py` to pad newlines failed to match the `()` due to using `\([^)]+\)` instead of `\([^)]*\)`.

## Status
CLOSED

## Root Cause
The regex `\([^)]+\)` requires at least one character inside the parentheses, but the placeholder generated by `book_layout_extractor.py` is `![...]()`, which has zero characters inside the parentheses.

## Decision Gate
No new design decision is required. The fix simply corrects a regex quantifier from `+` (one or more) to `*` (zero or more).

## Resolution
- Change `\([^)]+\)` to `\([^)]*\)` in `src/scripts/md_to_docx.py`.

## Bug Description
原生「另存新檔」檔案總管視窗固定在最上層（Always on Top），使用者點擊其他應用程式視窗時，對話框無法動態下移或被覆蓋，阻礙多工作業。

## Status
CLOSED

## Root Cause
`src/scripts/native_dialog.py` 在初始化 Tkinter `root` 視窗時設定了 `root.attributes('-topmost', True)`，且將 `root` 作為 `parent` 傳遞給 `filedialog.asksaveasfilename`。因未解除該屬性，Windows 系統將 `WS_EX_TOPMOST` 樣式強制套用於原生另存新檔對話框及其父視窗，導致對話框永久固定在 Windows 最頂層 Z-order 帶，無法正常響應點擊切換視窗時的上下層動態層疊。

## Decision Gate
No new design decision is required.
修復方式僅調整視窗屬性生命週期：在將視窗帶至最前台並觸發焦點後，立即調用 `root.update()` 並將 `topmost` 屬性重設為 `False`，使對話框既能在呼叫時正常顯示於瀏覽器前方，又不會被永久鎖定在最頂層。

## Resolution
- 在 `src/scripts/native_dialog.py` 中，於 `root.lift()` 與 `root.attributes('-topmost', True)` 後加入 `root.update()` 與 `root.attributes('-topmost', False)`，解除永久置頂鎖定。

## Bug Description
1. 圖片提取通道在提取 Word (.docx) 文件時，會將歷史已被使用者刪除的圖片一併提取下載。
2. 提取圖片若勾選「轉為灰階」，含 Alpha 透明通道的圖片（如透明 PNG）其透明區域會被填充為純黑底色。

## Status
CLOSED

## Root Cause
1. Word (.docx) 在使用者刪除圖片後，僅會自 `word/document.xml`（及相關 `.rels`）中解除引用，但 OpenXML 打包引擎並不會主動自 ZIP 內部的 `word/media/` 目錄清除實體圖片檔案。原實作直接遍歷 `word/media/` 下的所有檔案，導致歷史孤立圖片被全數提取。
2. 原實作在轉灰階時直接呼叫 Pillow 的 `img.convert("L")`，該操作會直接丟棄 Alpha 透明通道。由於多數透明圖片的透明像素 RGB 初始值為 `(0, 0, 0)`，移除 Alpha 通道後直接換算為亮度 0，導致原本透明的背景區域全數變成黑色實心區塊。

## Decision Gate
No new design decision is required.
此修復維持原模組責任、對外介面與 API 不變，僅在內部實作層加入活躍引用關係解析及安全的灰階透明度轉換輔助邏輯。

## Resolution
- 在 `src/scripts/extract_images.py` 中新增 `get_active_docx_media_entries(z)`：透過動態解析 `word/document.xml`、頁首、頁尾、註腳等活躍 XML 部件及其對應 `.rels` 關聯表，僅提取在文件中真正被引用的圖片，過濾已刪除孤立檔案；並保留 XML 解析異常時的回退機制。
- 新增 `convert_to_grayscale_helper(img, ext)`：
  - 支援透明度的格式（如 `.png`、`.webp`、`.tif`）：保留 Alpha 通道（轉為 `LA` 模式），並將完全透明像素（`A==0`）的底色亮度清理為純白（255），徹底防止透明區域變黑。
  - 不支援透明度的格式（如 `.jpg`、`.bmp`）：先行與純白底色進行 Alpha 合成，再轉為 `L` 模式，確保透明背景轉化為乾淨白底而非黑底。
- 同步更新 `extract_from_docx` 與 `extract_from_pdf` 使用該灰階轉換邏輯。

## Bug Description
書籍全自動整稿管線中，在 PDF → MD 階段未識別章節標題，所有段落均退化為普通段落，導致轉為 Word 時全部套用同一種正文字型與樣式，階層完全喪失。

## Status
CLOSED

## Root Cause
1. UI 字體審閱 Modal 將未設定字體預設為「忽略」，使用者點擊套用時將全書字體以 `{"role": "忽略"}` 全域寫入 `config/fonts.json`；後端 `book_layout_extractor.py` 將其判定為 `_is_ignored_font` 並阻斷所有 Fallback 啟發式與正則標題規則，導致標題辨識數直接歸零。
2. `HeadingDetector.detect_block_level` 僅讀取 `block.get("lines", [])`，而 Surya OCR 模組輸出的 block 物件使用 `surya_text`，導致掃描版 OCR 書籍之標題辨識率 100% 為 0。
3. 章節正則缺少「節/講/回/阿拉伯數字編號」覆蓋，且未過濾含特殊前導點之目錄行（TOC leader dots）。

## Decision Gate
ADR-003：
1. 前端 Modal 預設選項改為「自動（依規則辨識）」，儲存時不將未變更項目以「忽略」寫入全域 `fonts.json`。
2. 後端支援 `remove_keys` 允許重置字體對應。
3. `HeadingDetector` 支援 Surya OCR 的 `surya_text` 與頂層 `bbox`。
4. 擴充章節正則並強化目錄前導點識別，雙通道（標準版與 `*_no_footnote.py`）同步實作。

## Resolution
- `src/founder_tools/core/heading_detector.py`：新增 `block.get("surya_text")` 回退與擴展章節正則。
- `src/scripts/book_layout_extractor.py` & `src/scripts/book_layout_extractor_no_footnote.py`：擴充章節正則支援 `[节節回讲講]`、`Chapter` 與阿拉伯數字；增強 `is_toc_line` 過濾。
- `src/scripts/pdf_font_analyzer.py` & `src/web/app.py`：`analyze_pdf_for_ui` 預設角色改為 `auto`，`save_fonts_json` 與 API 支援 `remove_keys`。
- `src/web/static/ocr_pipeline.html`：預設選單改為「自動（依版面與章節規則辨識）」，避免無意識全域寫入「忽略」。
- 清理 `config/fonts.json` 殘留的 25 筆全域「忽略」標記。
- 新增 `tests/test_heading_detector.py` 並維護 `tests/test_font_analyzer_ignore.py` 全數綠燈通過。
